# Tech Conferences

iCal (.ics) calendars of tech conferences.

**Browse the lists:** [All calendars](https://ariskox.github.io/TechConferences/) · [Athens tech conferences](https://ariskox.github.io/TechConferences/tech.html) · [iOS conferences in Europe](https://ariskox.github.io/TechConferences/ios.html)

To subscribe, add a URL below to your calendar app (Google Calendar: *Other calendars → From URL*; Apple Calendar: *File → New Calendar Subscription*).

### Athens tech conferences

IT, tech, TEDx and related conferences in Athens, Greece. [View the list](https://ariskox.github.io/TechConferences/tech.html)

```
https://raw.githubusercontent.com/ariskox/TechConferences/main/athens-tech-conferences.ics
```

### iOS conferences in Europe

iOS, Swift and Apple-platform developer conferences in Europe. [View the list](https://ariskox.github.io/TechConferences/ios.html)

```
https://raw.githubusercontent.com/ariskox/TechConferences/main/ios-conferences-europe.ics
```

The web pages read the .ics files directly, so they always show the current calendars. Each event includes the conference's official URL, location and notes.

### Updates

The calendars are maintained by hand: edit the `.ics` files and commit. Conferences whose dates are not announced yet are added once their dates are confirmed. Pull requests with new events are welcome.
