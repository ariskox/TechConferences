# Athens Tech Conferences

An iCal (.ics) calendar of IT, tech, TEDx and related conferences in Athens, Greece.

### Subscribe

Add this URL to your calendar app (Google Calendar: *Other calendars → From URL*; Apple Calendar: *File → New Calendar Subscription*):

```
https://raw.githubusercontent.com/ariskox/AthensTechConferences/main/athens-tech-conferences.ics
```

Each event includes the conference's official URL, location and notes.

### Updates

The calendar is maintained by hand: edit `athens-tech-conferences.ics` and commit. Conferences whose dates are not announced yet are added once their dates are confirmed. Pull requests with new events are welcome.
